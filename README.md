# qbcalc — Blackjack EV Calculator

A [SolidJS](https://solidjs.com/) + [Vite](https://vite.dev/) web app for calculating expected value (EV) in blackjack.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

The app is automatically deployed to [GitHub Pages](https://qaeu.github.io/qbcalc/) on every push to `main` via the [deploy workflow](.github/workflows/deploy.yml).
